# Wortschatz Studio · Nordic Frost

An elegant, distraction-free German vocabulary and verb conjugation trainer built for iPad, iPhone, and desktop.

Live Web App: **[https://anantha973.github.io/german-flashcards/](https://anantha973.github.io/german-flashcards/)**

---

## Features
- **Nordic Frost Light Aesthetic**: High-key Scandinavian linen canvas (`#FAF8F5`), frosted milk-glass card (`backdrop-filter: blur(20px)`), high-contrast ink typography (*Playfair Display* & *Plus Jakarta Sans*).
- **Conjugation-First Layout**: Dedicated structured badges for *Präsens (3. P.)*, *Präteritum*, and *Perfekt* (explicitly color-highlighting auxiliary *sein* vs *haben*).
- **Native German Pronunciation**: Uses the device's native Web Speech API (`de-DE`) with Apple Siri voices on iOS/macOS.
- **Spaced Repetition Intervals**: SuperMemo SM-2 inspired grading (*Nochmal*, *Schwer*, *Gut*, *Leicht*) with `localStorage` persistence.
- **Ergonomics**:
  - **Mac/Desktop Shortcuts**: `Space` (flip card), `1-4` (rating), `A` (audio), `Left/Right` (navigation).
  - **iPad/iPhone**: Touch swipe gestures, large thumb-friendly tap targets, PWA "Add to Home Screen" standalone support.
- **Unslop Design Standard**: Strictly built according to [@heydamir/unslop](https://github.com/heydamir/unslop) design principles—zero fake device frames, zero glowing blur blobs, zero emoji badges, strict 4px grid spacing.
